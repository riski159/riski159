## What I can do for you

- **SQL Server Health Check** — a fixed-scope review of your instance (performance,
  backup/DR readiness, security basics, configuration) delivered as a written report
  with a scorecard and a fix-first roadmap. Start here if you're not sure what's wrong.
- **Performance tuning** — wait-stats-driven diagnosis, expensive-query analysis,
  index strategy, MAXDOP / cost-threshold / memory configuration.
- **Backup & DR that actually restore** — backup coverage audits, log-backup
  strategy matched to your RPO, and restore drills (an untested backup is a hope,
  not a backup).
- **Fractional / part-time DBA** — a set number of hours per week: monitoring,
  maintenance, and someone senior to call when the database misbehaves.

Every engagement starts **read-only**: I look first, report what I find, and only
then propose changes. You can inspect my exact diagnostic scripts below — nothing
hidden, nothing that writes to your server.
